Execution boundary: Koschei Forge does not mint, sign, submit or hold wallet secrets in this version. A successful preflight means the launch plan passed these checks; it is not a guarantee of token safety, value, liquidity or Mainnet eligibility.

1 · Launch plan evidence

Each preflight returns a deterministic SHA-256 plan hash so the exact public configuration under review can be referenced later.

2 · ARVIS stays honest

ARVIS Deep Scan currently remains the existing asset-investigation surface. Pi-specific on-chain intelligence will be added through a dedicated adapter rather than faking Solana evidence.

3 · Safe signing boundary

Token issuance will only be enabled when Koschei can hand authorization to an approved wallet/Pi flow without collecting the issuer or distributor secret.
