Technical architecture

One Web3 control plane. Independent evidence boundaries.

ARVIS is the intelligence and evidence engine inside Koschei Web3. Its chain-native observations feed execution verification, defense validation, runtime containment and security operations without turning a dashboard, model or single collector into authorization authority.

Layer 01

ARVIS intelligence and evidence

ARVIS observes transactions, wallets, tokens, actor/deployer/creator relations, funding and flow evidence, launch behavior, liquidity and other Web3-native security facts while preserving source identity and collection limits.

Layer 02

Execution verification

Execution Proof binds approved intent to transaction identity, policy context, calldata and known execution state before authority can cross a signing boundary.

Layer 03

Defense validation

Controlled attack and matched benign scenarios are evaluated against exact control configurations. Independent observation determines caught-in-time, late, missed, false-positive, clean or incomplete outcomes.

Layer 04

Runtime containment

Node Shield is intended to bind the approved artifact and effective runtime authority to local deployment policy, with live kernel-level evidence required before the runtime layer is treated as proven.

Layer 05

Evidence and decision plane

Shared evidence contracts keep ARVIS source facts, execution observations, rule identity, limitations and deterministic decisions distinct from explanatory language or UI presentation.

Layer 06

Security operations and integration

ARVIS investigations, cases, monitoring, alerts, APIs, webhooks and exports consume the same evidence record so operational delivery does not create competing technical truth.

Authority boundaries

What the architecture refuses to collapse

CustodyNot required

Security analysis is designed without private-key or asset custody.

ModelsNot verdict authority

AI may explain evidence but cannot own the deterministic security decision.

UINot authorization

A score or rendered state cannot substitute for the underlying proof chain.

UnknownsFail closed

Incomplete evidence remains incomplete instead of silently becoming safe.
