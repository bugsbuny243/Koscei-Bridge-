How the proof chain works →
01 · Identity

Canonical transaction identity

Recompute the transaction identity locally instead of trusting caller-supplied hashes, labels or allow flags.

02 · Policy

Bound authorization context

Bind artifact, policy, calldata and signer authorization to the same evidence envelope.

Pinned-state verification

Evaluate the exact payload against a known execution state and preserve the result for later review.
