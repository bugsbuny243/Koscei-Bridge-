Runtime defense

Node Shield

Node Shield is the runtime containment and attestation layer intended to prove that the artifact and effective runtime authority match the approved deployment policy. It remains behind its live Linux/BPF proof gate and is not presented here as production-complete.

Cross-chain trust

One security layer, chain-native evidence.

Koschei is not a Solana-only scanner. Ethereum/EVM, Solana and future chain adapters feed the same evidence model without pretending different chains have identical mechanics. Pi ↔ Solana remains a native adapter path, not a fake EVM wrapper.

Semantics defined

Bridge reserve / supply

The invariant model includes reserve/supply semantics; the concrete EVM evaluator is in v0.3 validation and chain-specific adapters come separately.

Adapter planned

Pi ↔ Solana

Vault, mint and burn authorization will reuse cross-chain proof semantics with native evidence adapters.

Expansion path

Multi-chain control plane

New chains join through evidence adapters without redefining the core ALLOW/BLOCK contract.
